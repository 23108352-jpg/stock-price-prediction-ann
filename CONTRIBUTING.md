# Contributing Guidelines

Thank you for your interest in contributing to **Stock Market Trend Prediction Using ANN**!

---

## 🛠 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/stock-ann-prediction.git
cd stock-ann-prediction
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Set Up Environment
```bash
pip install -r requirements.txt
```

### 4. Make Your Changes
- Keep code clean and well-commented
- Follow existing file structure
- Test your changes locally before pushing

### 5. Commit & Push
```bash
git add .
git commit -m "feat: add your feature description"
git push origin feature/your-feature-name
```

### 6. Open a Pull Request
Go to GitHub and open a Pull Request against the `main` branch.

---

## 📐 Code Style
- Max line length: **100 characters**
- Use **snake_case** for variables and functions
- Add docstrings to all functions
- Use type hints where possible

---

## 💡 Ideas for Contribution
- Add LSTM / RNN comparison
- Add more technical indicators
- Improve Streamlit UI
- Add unit tests
- Add sentiment analysis feature
- Support multi-stock comparison

---

## 🐛 Reporting Bugs
Open a GitHub Issue with:
- Steps to reproduce
- Expected vs actual behaviour
- Python version and OS
